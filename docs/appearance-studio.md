# 外观工作台与界面精修

本轮以学习内容为主：缩小宣传式大标题和插画，统一系统字体、按钮边角、标签层次与移动底栏。图标沿用既有 Iconfont 图标体系。动效用于按压、页面进入和状态变化；系统减少动画设置仍优先生效。

“我的花园”提供六套起始搭配，可以继续组合五种页面配色、五种重点色方案、三种卡片质感、三种背景、两种边角和两种首页布局。首页模块支持排序，计时、成长和笔记可收起，每日任务始终保留。最多收藏六套命名搭配，支持应用、删除、撤回上一步及恢复默认。恢复默认不删除收藏。

个人外观与本机收藏写入 `english-garden.preferences`，与云端学习记录分开。已有五种主题偏好会保留并补全新字段；无效数据回退默认。

## 拖拽创作与共享

交互参考 [Canva 拖拽网站编辑器](https://www.canva.com/website-builder/drag-and-drop/) 的模板起步方式，以及 [Milanote 白板](https://milanote.com/product/online-whiteboard) 的自由排布。实现为本网站的有限画布，不依赖第三方账号。

画布内可拖动卡片右上角把手，放下后更新首页顺序；支持方向键。叶子、太阳、心意、书本四种装饰可添加、拖动、旋转、删除，最多八枚。装饰仅位于独立页眉，避免遮盖学习正文。坐标归一化保存，适应屏幕宽度；拖动每帧只更新 transform，释放后才更新 React 状态。手机正文仍能正常滚动。

登录后可将命名搭配“保存给两人使用”。两人均能在“搭配柜”查看、刷新并应用；各自选择时只改变自己的界面，不覆盖对方正在编辑的草稿。共享作品最多每人六套，只有作者可删除；删除共享记录不撤销已经应用的外观。个人收藏与共享保存是两个明确入口。暂不提供双方同时编辑同一画布的实时光标功能。

共享数据存于独立 `garden_looks` 表，不挤占笔记或留言。GET/POST/DELETE 复用成员及退出撤销验证；数据白名单与数据库 CHECK 双重校验。RLS 开启，浏览器角色无表/RPC直连权限。SQL trigger 用作者事务锁保障六套配额。

## 自由创作画布

“我的花园”顶部提供独立作品画布：图片上传、文字、便签、矩形、圆形、手绘笔迹可以自由排布，支持移动、缩放、旋转、图层、复制、删除、撤回/重做、背景与 PNG 导出。当前手机编辑器采用独立全屏对话框，底部常驻添加工具、上方保存与撤销，样式在底部抽屉调整。作品可设为自己的今日学习首页装饰，学习卡片不会被画布元素遮挡。

草稿与图片缓存按账号写入 IndexedDB。云端作品只允许两位成员查看及编辑，每人最多十份；保存带版本检查，冲突时要求重新打开，避免覆盖搭档更新。退出/切换账号立即重建编辑会话，图片 Blob URL 释放。共享为保存后读取，不是实时协同绘画。两人分别应用同一作品即可使用相同首页装饰。

图片限定 PNG/JPEG/WebP、单张 3 MiB；客户端重编码及缩小，私密桶和成员鉴权保护原图，每人最多二十张、合计 30 MiB。“管理我上传的图片”可清理素材；已保存画布的图片引用在数据库事务中受到保护。清理不用于云端作品的素材前应检查本机草稿及撤销记录。仅允许结构白名单和私有图片编号，不导入任意 HTML 或第三方序列化代码。

初版画布验证记录：真实 SQL 契约 `scripts/boards-sql-contract.sql`（事务回滚）；双账号业务回归 `scripts/boards-regression.mjs`、[脱敏结果](boards-regression.json)。覆盖鉴权、跨用户读取图片及编辑、版本冲突、作者删除限制、大小写 UUID 引用保护；临时作品/图片均已清理，学习记录未改动。初版前端 63 条测试、工具模块覆盖率语句 99.57% / 分支 97.88% / 函数及行 100%，Supabase 27 条适配与输入校验测试通过。浏览器验证图片添加与 PNG 导出，320/390/1440px 无页面横向溢出；查看了手机编辑器和导出截图。

容量验收仍待验证：未确认目标 TPS、P95/P99、负载时长与资源预算，低频功能测试不代表并发容量通过；未对生产做压测或故障注入。

## 手机画布重做与验证（2026-10-09）

针对旧编辑器操作繁杂和移动端卡顿反馈，编辑渲染改用 MIT 许可的 [Konva](https://github.com/konvajs/konva/blob/master/LICENSE)。库与编辑器按需加载，学习主页无需先加载编辑引擎。现有 `BoardDocument` schema 1、私密图片编号和云端版本契约保留，本轮没有数据库结构变更。

编辑器打开后使用原生 modal dialog，背景不可操作，关闭后恢复页面滚动；手机键盘通过 visualViewport 高度调整编辑空间。单指选取、移动元素或绘画，空白处拖动平移；双指缩放和平移。元素选择框提供缩放及旋转，常用属性在底部面板，数字尺寸放入高级选项。三个起始模板（周末拼贴、给自己的海报、两个人的留言）和空白竖纸均为 900×1200，不预装外部图片。模板替换作为一次可撤销操作。输入与触控控件采用 16px 字号、至少 44px 常用点击区域。

帧内手势留在 Konva 节点和 refs，不在每次指针移动时重建 React 文档或写 IndexedDB。绘制由 requestAnimationFrame 合并；拖拽元素转入独立交互层，降低静态场景重复绘制。编辑像素比上限 1.5，图片预览缩至长边 1024，图片解码最多两条并行。图片读取缓存增量更新，所有缓存实例合计最多三次读取；删除引用、退出和切换身份释放私密 Blob URL。PNG 导出才临时创建 SVG，不在编辑过程中维持第二套隐藏场景；导出每段异步步骤检查账号与编辑会话是否仍有效。

文字和旋转使用面板本地缓冲。失焦、完成、关闭、保存、导出、切换面板、选择元素和模板替换前显式 flush，并以提交值去重，避免每个中文输入按键生成整张画布快照。撤销历史使用同步 ref 捕获同一批事件里的最新文档；复制和调整层级读取最新节点。拖动结束仅合并实际变化的几何字段，保留手势开始时尚未提交的新文字、颜色及未改变的角度。

草稿写入器在 250ms 窗口合并最新草稿，单个 owner 的不同组件实例串行写入。关闭、页面隐藏及卸载请求 flush；同账号重新挂载先等待已有写入完成，再读取草稿。失败保留待写草稿并明确报错，不将写入失败当作成功恢复。这些生命周期事件提高保存机会，但浏览器被系统立即终止时仍不能保证异步 IndexedDB 事务有时间完成。图片上传每段异步步骤重新检查会话，已退出的编辑器不向新作品追加节点。

本轮最终候选前端 87 项测试通过。已配置工具模块覆盖率：语句 99.19%、分支 96.81%、函数 98%、行 100%；不是整站组件或全项目覆盖率。回归包含模板契约及 UUID 独立、草稿合并/事务失败/恢复屏障、图片缓存并发与释放、导出取消、手势几何与文本提交后拖动保护。两个真实账号完成输入缓冲保存、搭档打开编辑和设为首页的低频业务验证。

性能对比使用同一 Windows Chromium 的本机生产构建 preview、390×844 视口和 CDP 6 倍 CPU 降速；这是前端模拟实验，不是生产服务器负载或实体手机测试。前后输入同样的十个字符，完成时间包含操作及约 800ms 的固定等待。开发模式耗时不纳入比较。普通作品为 31 个元素（20 个矩形、10 条各 200 点的笔迹、1 个便签），86,885 字节；极端作品为 100 个元素（99 条各 2,000 点的笔迹、1 个便签），8,074,008 字节，**超过云端 512 KiB 限制，仅作为本机草稿极端场景**，不是合法云端容量。
