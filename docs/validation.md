## 待补充与不适用项

| 项目 | 判定 | 原因与下一步 |
|---|---|---|
| 已部署真实 SQL 与基础权限 | 已有基础功能证据 | live-smoke 验证真实状态读写、版本冲突和直连拒绝；不把它扩大为所有 SQL 边界都通过 |
| 跨实例数据库锁竞争 | 待验证 | 本地模拟 RPC 调用不能证明云数据库在并发竞争下的租约与20条录音配额边界 |
| 状态 1 MiB 与多用户大数据 | 待验证 | 本地状态体积测试已有，真实 Supabase 标准化 jsonb 字节数、真实大状态保存与延时仍需实测 |
| 手机/电脑 E2E | 待验证 | 需最终版本的页面、设备、浏览器、主题与布局、录音权限和状态持久化实际截图/断言 |
| AI 真实反馈 | 待验证 | 当前云端未配置密钥，503 是正确的未启用行为；没有成功反馈、计费或真实延时证据 |
| AI 下游 500/超时/恢复 | 本地边界通过，真实隔离环境待验证 | 已有模拟故障及无重试断言；未经授权不对生产服务做故障注入 |
| Storage 响应丢失补偿 | 本地边界通过，真实故障环境待验证 | 模拟已提交后丢响应、清理失败保留记录与配额；没有在真实云端故意制造故障 |
| 业务成功 TPS、客户端 P95/P99、错误率 | 待验证 | 尚未预先确认目标 TPS、延时、并发、数据分布、持续时间与资源上限；22次功能样本不能替代容量验收 |
| PostgreSQL 执行计划与资源等待 | 待验证 | 未附慢 SQL、扫描行数、连接等待和目标负载下的资源指标 |
| 线上同负载前后对照 | 待验证 | 没有完整容量基线及同负载复测，不能宣称线上性能问题已解决 |
| 缓存冷热与失效 | 不适用 | 应用当前无缓存层；浏览器静态资源缓存不替代私密学习状态数据库 |
| Node SQLite 与 Supabase 同一容量结论 | 不适用 | 本地 SQLite 和云端 PostgreSQL/Storage 是不同环境，性能证据不能互换 |
| 正式雅思成绩预测 | 不适用 | 原创微练习、合成语音与参考评语不是完整正式试卷或官方评分 |

后续若做容量验收，先由项目确认成功 TPS、客户端 P95/P99、错误率、并发/到达率、持续时间、真实数据和账号分布、资源上限，再在明确授权的隔离环境测试。记录版本、配置、预热与测量时间窗、原始结果、依赖失败和资源等待。所有必需指标同时达标后才能给出性能通过结论，不能反向根据测得结果选择阈值。
