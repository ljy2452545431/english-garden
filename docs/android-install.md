# 小米手机安装与使用

1. 在手机上打开本项目 GitHub Releases 下载页，下载 `english-garden-1.0.0.apk`。
2. 下载完成后点开文件；若系统询问安装来源权限，仅允许这次使用的浏览器或文件管理器安装，然后返回继续安装。
3. 桌面上打开“英语花园”。想先听课程，可点“先体验站内课程”；进入“课堂”，选择词汇或听力后点“朗读”。
4. 两人同步学习时，使用原来的 ljy / jfl 账号和现有密码登录。第一次录口语时，选择允许麦克风；听课程无需麦克风权限。
5. 导出录音、图片或学习记录时，选择系统保存窗口中的文件夹，再点保存。恢复学习记录使用JSON文件选择器。

适用安卓8.0及以上，需设备上的 Android System WebView 保持更新。小米不同系统版本的安装提示名称可能略有不同。

## 网页与 App 的区别

- App内置414份基础合成教学音频，可离线体验课程；登录、双人共享、上传和AI等联网功能仍需网络。
- App与浏览器的本机数据分开保存。要读取已同步的学习记录，请在App中登录原账号；浏览器中未同步的本机草稿不会自动迁移。
- 网页更新后，已安装App的内置课程不会自动替换。后续发布同签名新版APK后，直接覆盖安装；无需先卸载，以免丢失本机草稿。
- 本版本为直接安装包，未上架小米应用商店。

若仍听不到声音：先调高手机“媒体音量”，再点一次朗读。若出现音频加载提示，保留提示文字以便定位。课程朗读是基础合成声音，不是雅思官方试卷录音。
